# Part 2: Vectors

From measuring pixels to representing what an image shows. Neural networks learn their own
features, pre-trained models turn every image into a vector, and those vectors let you search,
cluster and classify a collection with very few labels. The last module asks what these models
get wrong, and for whom.

A GPU is recommended for this part (*Runtime → Change runtime type → T4 GPU*).

| # | Module | In short |
|---|--------|----------|
| 05 | [Convolutional Neural Networks for Images](05_cnns_for_images/) | convolutions as learned filters, training a small CNN, augmentation and overfitting, looking inside the network |
| 06 | [Transfer Learning and Image Embeddings](06_transfer_learning_and_embeddings/) | pre-trained backbones, linear probes and fine-tuning, similarity search, near-duplicates, clustering images into visual themes |
| 07 | [Bias, Measurement and Faces](07_bias_measurement_and_faces/) | who models were trained on, auditing a classifier across groups, skin tone versus racial categories, what not to infer from a face |

If you took Bags, Vectors & Transformers, this part does for images what Day 2 did for words.
