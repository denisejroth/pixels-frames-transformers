# Part 5: Doing It for Real

What it takes to move from a notebook that works on a few hundred images to a study you can
defend and others can repeat. One module adapts a vision-language model to your own coding
scheme, one deals with images that no camera took, and one covers the practical side of large
media collections.

| # | Module | In short |
|---|--------|----------|
| 17 | [Fine-Tuning a Vision-Language Model](17_fine_tuning_a_vlm/) | when fine-tuning pays off, LoRA on a small VLM, prompted versus fine-tuned on the same test set, side effects |
| 18 | [Generated Images](18_generated_images/) | how image generators work, generated images in your data, provenance, generated stimuli for experiments, auditing generators for bias |
| 19 | [Scaling Up and Reproducibility](19_scaling_up_and_reproducibility/) | storage formats, batching and caching, pinning models, Colab versus a cluster, sharing data you can't redistribute, documentation |
