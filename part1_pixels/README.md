# Part 1: Pixels

The foundations. What an image is to a computer, how to build a collection of images you are
allowed to use, which simple measurements you can take from pixels, and how to code images by
hand and train a first classifier. Everything in this part runs on a normal CPU runtime.

| # | Module | In short |
|---|--------|----------|
| 01 | [Images as Data](01_images_as_data/) | pixels, channels and color spaces; loading, resizing and showing images; what social scientists do with images |
| 02 | [Building an Image Corpus](02_building_an_image_corpus/) | where images come from, licenses and terms, people in pictures, downloading politely, duplicates, a corpus manifest |
| 03 | [Handcrafted Features](03_handcrafted_features/) | brightness, colorfulness and composition; counting faces; reading visible text; what a feature does and doesn't measure |
| 04 | [Coding Images and Classic Classifiers](04_coding_images_and_classic_classifiers/) | visual codebooks, agreement, a classifier on handcrafted features, and why it hits a ceiling |

By the end of Part 1 you will have a small, documented image corpus with hand-coded labels, which
later modules come back to.
